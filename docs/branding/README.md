# Logo Widget Premium

- `logo-1024.png`: logo do chủ dự án cung cấp (ảnh 1024×1024, nền trong suốt ở bốn góc bo).
- Biểu tượng ứng dụng (adaptive icon) gồm hai lớp trong `app/src/main/res/drawable-nodpi/`: lớp nền chuyển màu hồng, tím, xanh và lớp nổi là logo.

Các con số trong logo (10:09, 24, 15, 88%, 6.2/12 GB, 72/256 GB) chỉ là minh họa.
