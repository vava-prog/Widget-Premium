# Logo Widget Premium

Logo do dự án tự vẽ bằng vector (SVG), không dùng hình của bên khác.

- `logo.svg`: bản vẽ gốc, có thể chỉnh sửa.
- `logo-1024.png`: ảnh 1024×1024 (kính mờ hồng, tím, xanh; đồng hồ, lịch Âm – Dương, thời tiết, pin/RAM/bộ nhớ).
- Biểu tượng ứng dụng (adaptive icon) dùng hai lớp nền và nổi trong `app/src/main/res/drawable-nodpi/`.

Các con số trong logo (10:09, 12, 20, 87%, 62%, 58%) chỉ là minh họa.
